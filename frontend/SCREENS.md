# PayShare frontend screen checklist

Serve the repository with `python3 -m http.server 8080` and open `/frontend/prototype.html`. Use **Explore screens** for any direct route. The shared tokens and button styles are reused from `frontend/ui`. The [component showcase](ui/showcase.html) remains available.

The 127 listed frames include the desktop, mobile, 360px, and authored dark-mode variants. The cover, information architecture, user flows, and prototype pages informed the implementation. The archived v1 pages are outside this preview.

**Compared** means a Chromium screenshot was compared with that frame’s Figma export. **Browser only** means the screen rendered in Chromium and its local assets loaded. Figma’s plan limit blocked the extra reference screenshot for those rows.
